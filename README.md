One image built to get the AI judge most excited. Entry for make.fun's [ai-excited-01](https://make.fun/bounty/ai-excited-01) bounty ($250, top 20 paid).

## Run it

```sh
python3 main.py
```

`main.py` checks the shipped `entry.png` (JPEG opening bytes, exact byte size, SHA-256) and copies it to `/output/entry.png`.
